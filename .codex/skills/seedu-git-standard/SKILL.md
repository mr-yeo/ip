# SE-EDU Git Standard

Follow the SE-EDU Git conventions at https://se-education.org/guides/conventions/git.html for all git operations in this repository.

This project requires all future commits and branch-related work to follow these rules.

## Mandatory rules

- Use clear, meaningful branch names in kebab-case.
- If the work relates to an issue, prefer the form `issueNumber-keywords-from-issue-title`.
- Keep commit subject lines imperative, capitalized, and under 50 characters when possible.
- Do not end the subject line with a period.
- Use a blank line between the subject and body when a body is needed.
- Wrap the commit body at roughly 72 characters.
- Explain what changed and why, not just how.
- Prefer concise, well-scoped commits rather than large mixed-purpose commits.
- Use lightweight tags unless the task explicitly requests an annotated tag.
- Do not commit or push unless the task explicitly asks for it.

## Project enforcement

- Apply these conventions to all future commits in this repository.
- Before making a commit, verify that the subject line matches the SE-EDU format.
- Keep commit messages informative enough for a reviewer to understand the change without reading the full diff.
- Treat these rules as mandatory project policy for all future work.
